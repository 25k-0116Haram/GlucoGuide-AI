# GlucoGuide AI

Diabetes Awareness and Risk Education System.

## Project Overview
GlucoGuide AI is a Python-based educational project that provides diabetes awareness, health information, risk awareness, and data visualization.

## Features
- NLP-based Health Assistant
- Diabetes Risk Awareness
- Diabetes Health Information
- Data Visualization
- Machine Learning Analysis

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
